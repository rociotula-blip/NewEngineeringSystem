# V0.6 工程基本資料編輯與儲存

日期：2026-11-23

## 功能

1. 點選工程清單中的工程，將該工程**目前資料庫的真實資料**載入下方「編輯工程基本資料」表單。
2. 修改工程代碼、工程名稱、契約編號、開工日、預定完工日、實際竣工日，按 **儲存工程修改**。
3. 程式採用 SQLite `ATTACH DATABASE`，在同一個交易中同步更新工程資料庫的 `projects` 與工程清單資料庫的 `registered_projects`。不可只更新其中一份；錯誤時回滾。
4. 可以按 **新增／清空表單** 解除編輯模式，重新建立其他工程；雙擊工程列可查看資料。
5. 日期必須是存在的 `YYYY-MM-DD`，預定完工與實際竣工不得早於開工。工程代碼不可與其他已登記工程重複。
6. 不重新建立工程資料夾、不更動 `engineering.sqlite3` 路徑，也不重編施工批次、樁號。
7. 本版本不修改 schema，也不提升 schema version；與 V0.5.1 的 schema V6 相容。

## 原始檔交付（只修改三個檔案，不壓縮）

- `main.py`：新增選取載入、編輯／新增模式、儲存修改與清空按鈕。
- `project_manager.py`：新增 `get_project()` 與 `update_project()`，確認工程資料庫與 registry 一致，雙庫同步儲存。
- `tests/test_v05.py`：新增 3 項測試，涵蓋修改後重新開啟、重複代碼／日期驗證、原施工批次保存。
