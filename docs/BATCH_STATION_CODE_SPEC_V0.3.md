# 施工批次與樁號編碼規格 V0.3（正式設計修訂）

日期：2026-11-23  
狀態：**需求定義已由使用者更正；尚待同步修改 SQL、Python 產生器、驗證器並重跑測試。**
本規格取代 [V0.2 批次規格](BATCH_STATION_CODE_SPEC_V0.2.md) 的編碼部分，保留舊文件作為歷史紀錄。

## 核心設計：三個識別層級

1. **日期＋道路車道：11 碼**，僅作組合前綴，**不是完整的施工批次編號**：`YYYMMDDRRDL`。
2. **施工批次編號：14 碼**，`YYYMMDDRRDLBBB`。其中 `BBB` 為同日、同路線、同方向、同車道的**施工批次流水號 001～999**。
3. **施工樁號／分段識別：批次編號加上 `-SSS`**，`YYYMMDDRRDLBBB-SSS`，其中 `SSS` 是**該批次內**施工分段的序號 001～999（完整長度 18 字元，含連字號）。

| 欄位 | 長度 | 例子 | 定義 |
|---|---:|---|---|
| YYYMMDD | 7 | 1151123 | 民國 115 年 11 月 23 日 |
| RR | 2 | 01 | 國道 1 號 |
| D | 1 | S | 南向；N 為北向 |
| L | 1 | 3 | 第 3 車道；I 為內路肩，E 為外路肩 |
| BBB | 3 | 001 | 第 001 個**施工批次** |
| -SSS | 4 | -001 | 該批次的第 001 個**施工分段**，需要分段時才使用 |

例：
- `115112301S3001`：完整的施工**批次**碼。
- `115112301S3001-001`：這個批次的第一個**施工樁號**。
- `115112301S3001-002`：同批次第二個施工樁號。
- `115112301S3002`：同日、同國道、同方向、同車道的**另一批次**。
- `115112301SE001`：國道 1 號南下外路肩第 001 批。
- `115112301SI001`：國道 1 號南下內路肩第 001 批。

**先前設計錯誤**：將 `115112301S3`（11 碼）稱作施工批次，又把尾碼 `001` 當施工樁號。本次明確修正成「批次三碼 BBB」＋「分段三碼 -SSS」兩層各自流水，不混用。

## 工程模式與關聯

- **只管理到施工批次的工程**：保存 `batch_no=115112301S3001`、施工日期、道路／車道與施工範圍，該批施工明細直接關聯 `batch_id`，`station_id` 可為空；**不用產生 `-001`**。
- **管理到施工樁號的工程**：同一批次之下建立 `-001`、`-002` 等分段；每一分段獨立保存起訖里程、公尺數、長度、有效寬度與施工數量，施工明細關聯 `batch_id` 及 `station_id`。
- 起訖里程與批次、樁號序號都是**不同欄位**；`001` 不等於特定公里或 100 公尺。
- 可以 50m、100m 或自訂長度切段，尾段不滿設定長度則保留實際長度。
- 同一工程、同日、同路線、同方向及同車道可以有**多個批次**，由 BBB 區分；因此 V0.2「一日同車道只能一個批次」限制必須移除或修訂。

## 車道編碼

- `1`～`9`：行車車道。
- `I`：內路肩（Inner）。
- `E`：外路肩（Exterior），**已取代容易與數字 0 混淆的 O**。
- 外側行車車道不等於外路肩。匝道、輔助車道、爬坡道等特殊路型代碼待確認。

## 資料庫待修改項目（未完成，勿視為已實作）

- `work_batches`：將正式 `batch_no` 定義改成 14 碼；新增可索引欄位 `batch_sequence`（BBB），唯一性至少約束 `(project_id, batch_no)`，並防止相同車道同日重複 BBB。
- `work_stations`：將 `station_no` 由舊的 14 碼改成 **18 字元**，包含 `-SSS`；儲存 `station_sequence`（SSS），約束 `(batch_id,station_sequence)` 唯一。
- `project_station_preferences`：定義兩種工程紀錄精度（批次模式／批次＋樁號模式），實際驗證至少應依工程設定對未分段施工資料作檢查。
- 批次產生器：依指定日期、RRDL 取得該工程中的下一個 BBB；避免重複，考量同時使用時的交易鎖定。
- 分段產生器：以該批次獨立的 SSS 流水；驗證起訖里程、重複/重疊、尾段及超過 999 的情況。
- 關聯仍需用資料庫內部主鍵（`batch_id`、`station_id`），不可將顯示用編碼當作唯一資料外鍵來源。
- **既有 V0.2 空白 DB 與測試程式尚未按上述規格修改／重新測試；歷史 7 項測試不構成本版驗收。**
