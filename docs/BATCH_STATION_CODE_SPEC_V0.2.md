# 施工批次與施工樁號編碼｜資料庫規格 V0.2

建立日期：2026-11-23。此規格套用全新資料庫，與舊 V3.0 分開。

**2026-11-23 編碼修訂（正式決策）**：外路肩由 `O` 改為 **`E`（Exterior）**，避免英文字母 O 與數字 0 混淆；內路肩維持 `I`。`O` 是已停用舊設計碼，後續新資料與介面不得產生。此為文件規格修訂，**先前 V0.2 本機程式與 SQLite 約束仍須修改並重新測試**；原先 7 項通過的測試屬舊 `O` 版本，不代表 `E` 已經過程式驗收。

## 1. **批次**與**施工樁號**是兩個層級

- **施工批次碼（11 碼）**：`YYYMMDD + RRDL`。
- **施工段號／樁號（14 碼）**：`YYYMMDD + RRDL + SSS`。
- `YYY` 是民國三位年，`MMDD` 是月份及日期；`RR` 是兩位國道代碼（例如 `01`／`03`）；`D` 是 `N`（北）或 `S`（南）；`L` 是車道代碼；`SSS` 是批次內 001～999 流水號。
- **施工段號的流水號不是里程公里數**。實際起訖里程另外儲存為整數公尺，不得依序號猜測里程。
- `115112301S3`：115 年 11 月 23 日，國道 1 號南下第 3 車道的施工批次。
- `115112301S3001`：上述批次的第 001 段。
- `115112303N2002`：115 年 11 月 23 日，國道 3 號北上第 2 車道第 002 段。

## 2. 車道四碼 `RRDL`

| 車道碼 | 定義 |
|---|---|
| `01S3` | 國 1 南下第 3 車道 |
| `03N2` | 國 3 北上第 2 車道 |
| `01SI` | 國 1 南下**內路肩**，I = Inner shoulder |
| `01SE` | 國 1 南下**外路肩**，E = Exterior shoulder |
| `03NI` | 國 3 北上內路肩 |
| `03NE` | 國 3 北上外路肩 |

允許一般車道數字 `1`～`9`；肩部只用 `I`、`E`。**外車道與外路肩不同**，不可把舊系統的「外」直接轉成 `E`。匝道、爬坡道及特殊車道另待討論編碼。

## 3. 里程與編號例子（100m 設定）

| 施工段號 | 起訖里程 | 實際長度 |
|---|---|---|
| `115112301S3001` | 180k+800～180k+900 | 100m |
| `115112301S3002` | 180k+900～181k+000 | 100m |
| `115112301S3003` | 181k+000～181k+050 | 50m（末段） |

可選 50m、100m 或自訂正整數公尺；不足一個完整分段保留尾段。單批上限為 999 段；同批里程不可重疊，段號不可重複。

## 4. 已建立的資料庫結構（本地開發套件 V0.2）

- `work_batches.batch_no`：11 碼，`(project_id,batch_no)` 唯一。
- 新增 `work_stations`：記錄 14 碼 `station_no`、批次、工程、路線、流水號、起訖公尺、設定長度、尾段標記。
- 新增 `project_station_preferences`：每個工程的預設切段長度和是否允許自訂。
- `work_operations.station_id`：將該段的刨除、鋪設、標線或線圈施工紀錄連到分段；不按里程的作業可暫留空。
- SQLite 觸發器檢查工程、批次、日期、路線、方向、車道及里程是否一致，拒絕重疊及重複序號。
- 資料庫採 **schema 版本 2**：由舊版**本專案** V0.1 遷移時，先保存一份備份，再新增表格與欄位。**不遷移舊 V3.0。**
- 工程內可有不同日期及車道的批次；初版「同工程、同日、同路線方向車道」只有一個批次。若同日同車道有多個獨立施工隊／獨立時段，後續要增加次批次設計，不能繼續使用相同代碼。

## 5. 已通過的本地測試

已建立 **33 張應用資料表**（比 V0.1 多 2 張），schema version 2，SQLite integrity_check = ok。7 項自動測試通過，包含：

- `01S3`、`03N2`、內路肩 `I`、外路肩 `E`、民國日期。
- 50m、100m、自訂 75m、最後不滿一段、超出 999 上限。
- 相同批次重複建立、同批里程重疊阻擋、日期與編碼不符阻擋。
- 原本施工數量 → 日誌 → 試驗 → 估驗 → 照片資料關聯測試。
- V0.1 → V0.2 升級、備份、跨工程保護及資料庫完整性。

測試為資料庫層測試，未代表 Windows GUI 驗收通過。

## 6. 仍需一起確認的規格

1. 若同一天同國道同方向同車道施工兩個不連續區間，是**同一批次下不同段號**（初版建議），還是需另設子批次？
2. 車道 `1`～`9` 中，哪一個是最外側行車車道，需依實際路段車道設定判定，不能用 `E` 表示。
3. 匝道、爬坡道、輔助車道、內外側路肩是否全需獨立編碼？四碼的單字元車道欄位可能不夠，需要拓展路段子類別。
4. 施工分段修改後，如何保留對應施工量、照片、試驗及已估驗資料的稽核歷程？
